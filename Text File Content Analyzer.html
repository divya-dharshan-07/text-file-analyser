Problem and users


Read a text file and count its characters, words and lines. Count how often each of the 26 letters appears, then report the most frequent letter. Tie rule: when several letters share the highest count, all of them are listed in alphabetical order.


Users are students and teachers who want a quick profile of a text file. C concepts covered: strings, pointers, loops, functions and file handling.




Inputs
A file name typed at the prompt (up to 255 characters, no spaces).
Outputs
A report on screen and the same report saved to report.txt.


Constraints
Only English letters A to Z are counted, case-insensitively. Digits and symbols count as characters but not as letters. The file opens in binary mode so every byte is counted.




Algorithm


open file
for each byte c until end of file:
    characters++
    if c is newline: lines++
    if c is whitespace: inWord = false
    else if not inWord: words++, inWord = true
    if c is a letter: frequency[lower(c) - 'a']++
if characters > 0 and last byte is not newline: lines++
max = largest frequency
print every letter whose frequency equals max


A word is a run of non-whitespace characters. The final line counts even without a trailing newline.

Edge cases handled


  • Empty file: all counts are 0 and the report says no letters were found.
    • 

  • Missing trailing newline: the last line is still counted.
    • 

  • Whitespace-only and digit-only files: zero words or zero letters, with no crash.
    • 

  • Windows line endings: \r counts as a character and as whitespace.
    • 

  • Non-ASCII bytes: cast to unsigned char before isalpha to avoid undefined behavior.
    • 

  • Bad input: unreadable file name or failed fopen prints an error and exits with code 1.







Complexity


Time: O(n) for a file of n bytes, because each byte is read once. Space: O(1), because the program keeps 26 counters and a few variables whatever the file size. Finding the maximum scans 26 entries, which is constant.


Viva questions


Why use a struct?
It groups related results and lets analyzeFile update them through one pointer instead of several.


Why open the file with "rb"?
Binary mode counts every byte the same on every system, with no newline translation.


Why cast to unsigned char before isalpha?
ctype.h functions accept values from 0 to 255 or EOF. A negative char value is undefined behavior.


How do you detect words?
A flag inWord flips to 1 on the first non-space character and back to 0 on whitespace, so each run is counted once.


What happens on a tie?
Every letter equal to the maximum is printed in alphabetical order, as in the l o r result above.


Why one displayReport for screen and file?
It takes a FILE *out, so passing stdout or the report file reuses the same code with no duplication.

#include <stdio.h>
#include <ctype.h>

typedef struct {
    long characters;
    long words;
    long lines;
    long frequency[26];
} Analysis;

void analyzeFile(FILE *file, Analysis *a) {
    int ch, inWord = 0, lastChar = -1;

    while ((ch = fgetc(file)) != EOF) {
        unsigned char c = (unsigned char)ch;
        a->characters++;
        lastChar = ch;

        if (ch == '\n')
            a->lines++;

        if (isspace(c)) {
            inWord = 0;
        } else if (!inWord) {
            a->words++;
            inWord = 1;
        }

        if (isalpha(c)) {
            int lower = tolower(c);
            if (lower >= 'a' && lower <= 'z')
                a->frequency[lower - 'a']++;
        }
    }

    if (a->characters > 0 && lastChar != '\n')
        a->lines++;
}

void displayReport(FILE *out, const Analysis *a) {
    long max = 0;
    int i;

    for (i = 0; i < 26; i++)
        if (a->frequency[i] > max)
            max = a->frequency[i];

    fprintf(out, "\n=== TEXT FILE CONTENT ANALYZER ===\n");
    fprintf(out, "Characters: %ld\n", a->characters);
    fprintf(out, "Words     : %ld\n", a->words);
    fprintf(out, "Lines     : %ld\n", a->lines);

    fprintf(out, "\nLetter Frequencies:\n");
    for (i = 0; i < 26; i++) {
        if (a->frequency[i] > 0)
            fprintf(out, "%c : %ld\n", 'a' + i, a->frequency[i]);
    }

    if (max == 0) {
        fprintf(out, "\nNo English letters found.\n");
    } else {
        fprintf(out, "\nMost frequent letter(s): ");
        for (i = 0; i < 26; i++)
            if (a->frequency[i] == max)
                fprintf(out, "%c ", 'a' + i);
        fprintf(out, "\nMaximum frequency: %ld\n", max);
    }
}

int main(void) {
    char filename[256];
    FILE *input, *report;
    Analysis a = {0};

    printf("Enter input filename: ");
    if (scanf("%255s", filename) != 1) {
        printf("Invalid filename input.\n");
        return 1;
    }

    input = fopen(filename, "rb");
    if (input == NULL) {
        printf("Error: Cannot open input file.\n");
        return 1;
    }

    analyzeFile(input, &a);
    fclose(input);

    displayReport(stdout, &a);

    report = fopen("report.txt", "w");
    if (report == NULL) {
        printf("\nCould not create report.txt\n");
        return 1;
    }

    displayReport(report, &a);
    fclose(report);

    printf("\nReport saved to report.txt\n");
    return 0;
}
